##  Технологический стек

- **React 19.2.0** - UI библиотека
- **React Router DOM 6.26.0** - маршрутизация
- **Vite 7.2.4** - сборщик и dev-сервер
- **Tailwind CSS 3.4.0** - CSS фреймворк для стилизации
- **Axios 1.7.0** - HTTP клиент

##  Требования

- Node.js (рекомендуется версия 18+)
- npm или yarn

##  Установка и запуск

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:5173` (или другому порту, который укажет Vite)

##  Основные функции

### Аутентификация
- Регистрация новых пользователей
- Вход в систему с JWT токеном
- Автоматическое сохранение сессии в localStorage
- Защищенные маршруты (ProtectedRoute)
- Автоматический редирект при 401 ошибке

### Главная страница (Home)
- Лента постов от подписок
- Автоматическая загрузка при монтировании
- Отображение постов в виде карточек

### Профиль пользователя
- Просмотр профиля по имени пользователя
- Редактирование профиля (имя пользователя, полное имя, описание)
- Загрузка и обновление аватара
- Смена пароля
- Отображение постов пользователя

### Посты
- Создание постов с медиа файлами
- Просмотр детальной информации о посте
- Редактирование своих постов
- Удаление своих постов
- Лайки и комментарии

### Подписки
- Подписка/отписка на пользователей
- Отображение количества подписчиков и подписок

### Поиск
- Поиск пользователей по имени и полному имени (username, full_name)
- Панель поиска с модальным окном

### Уведомления
- WebSocket подключение для real-time уведомлений
- Панель уведомлений с счетчиком непрочитанных
- Автоматическое обновление при новых уведомлениях

### Explore
- Страница с рекомендациями

### Темная тема
- Переключение между светлой и темной темой
- Сохранение выбранной темы в localStorage
- Автоматическое определение системной темы
- Плавные переходы между темами

##  API интеграция

Приложение использует REST API и WebSocket для связи с бэкендом.

### Базовый URL
По умолчанию: `http://localhost:8080/api`

Настройка находится в `src/http-common.js`. Для изменения URL бэкенда отредактируйте значение `baseURL`.

### Интерцепторы Axios

**Request интерцептор:**
- Автоматически добавляет JWT токен из localStorage в заголовок `Authorization: Bearer <token>`

**Response интерцептор:**
- При получении 401 ошибки удаляет токен из localStorage
- Перенаправляет на страницу входа (кроме страницы `/login`)

### Сервисы

#### auth.service.js
- `login(username, password)` - вход в систему
- `register(userData)` - регистрация
- `getProfile()` - получение профиля текущего пользователя
- `updateProfile(data)` - обновление профиля
- `changePassword(oldPassword, newPassword)` - смена пароля
- `uploadAvatar(file)` - загрузка аватара
- `getUserByUsername(username)` - получение пользователя по username
- `getUserById(userId)` - получение пользователя по ID
- `searchUsers(query)` - поиск пользователей
- `logout()` - выход из системы

#### post.service.js
- `getUserPosts(userId)` - получение постов пользователя
- `getFeedPosts()` - получение ленты постов
- `deletePost(postId)` - удаление поста
- `updatePost(postId, data)` - обновление поста

#### follow.service.js
- `follow(userId)` - подписка на пользователя по ID
- `unfollow(userId)` - отписка от пользователя по ID
- `checkFollow(followingId)` - проверка, подписан ли текущий пользователь на указанного пользователя
- `getFollowers(userId)` - получение списка подписчиков пользователя
- `getFollowing(userId)` - получение списка пользователей, на которых подписан текущий пользователь
- `getFollowInfo(userId)` - получение сводной информации о подписках и подписчиках пользователя

#### useNotifications.js
- WebSocket подключение для уведомлений
- Получение количества непрочитанных уведомлений
- Обновление уведомлений в реальном времени

##  Стилизация

Проект использует **Tailwind CSS** для стилизации. Конфигурация находится в `tailwind.config.js`.

##  Маршрутизация

Маршруты определены в `src/App.jsx`:

| Путь | Компонент | Доступ |
|------|-----------|--------|
| `/` | HomePage | Только для авторизованных |
| `/login` | LoginPage | Публичный |
| `/register` | RegisterPage | Публичный |
| `/profile` | ProfilePage | Только для авторизованных |
| `/profile/:username` | ProfilePage | Только для авторизованных |
| `/edit-profile` | ProfileUpdatePage | Только для авторизованных |
| `/explore` | ExplorePage | Только для авторизованных |
| `/p/:id` | PostPage | Только для авторизованных |
| `/search` | UserSearchModal | Только для авторизованных |
| `*` | Redirect to `/` | Все остальные пути |

### Защищенные маршруты
Компонент `ProtectedRoute` проверяет авторизацию пользователя:
- Если пользователь не авторизован, перенаправляет на `/login`
- Во время проверки показывает индикатор загрузки

##  Аутентификация

Аутентификация реализована через React Context (`AuthContext`).

### Использование:
```jsx
import { useAuth } from './context/AuthContext';

function MyComponent() {
  const { user, isAuthenticated, login, logout } = useAuth();
  
  // Использование данных пользователя и методов
}
```

### Доступные методы и свойства:
- `user` - объект текущего пользователя
- `token` - JWT токен
- `isAuthenticated` - булево значение, авторизован ли пользователь
- `loading` - состояние загрузки
- `login(username, password)` - вход в систему
- `register(userData)` - регистрация
- `logout()` - выход из системы
- `setUser(userData)` - обновление данных пользователя

##  Управление состоянием

- **React Context API** - для глобального состояния аутентификации
- **React Hooks (useState, useEffect)** - для локального состояния компонентов
- **localStorage** - для хранения токена и темы

##  Уведомления

Уведомления реализованы через:
- **React Hot Toast** - для toast уведомлений (успех/ошибка)
- **WebSocket** - для real-time уведомлений (через `useNotifications`)

### Пример использования toast:
```jsx
import toast from 'react-hot-toast';

toast.success('Успешно!');
toast.error('Произошла ошибка');
```

##  Темная тема

Темная тема настраивается через:
- Переключатель в Sidebar
- Сохранение в localStorage с ключом `theme`
- Автоматическое определение системной темы при первом запуске

### Утилита theme.js
Функция `initTheme()` вызывается при старте приложения и устанавливает класс `dark` на `html` элементе в зависимости от сохраненной темы или системных настроек.


##  Известные проблемы и ограничения

- Приложение рассчитано на десктопную версию (минимальная ширина контента)
- Все изображения загружаются через бэкенд API
- Все страницы требуют авторизации
